# Замер скорости скачивания

Консольный скрипт на Node.js делает 10 последовательных GET-запросов к одному URL. Каждый запрос завершается после чтения всего тела ответа. Скрипт читает данные порциями и сразу подсчитывает их размер.

## Запуск

Нужен Node.js 22 или новее. Устанавливать зависимости не требуется. Выполните из папки репозитория:

```bash
node speed-test.mjs "https://example.com/"
```

Для замера используйте прямой HTTP(S)-адрес большого файла, например изображения, который возвращает статус 2xx. При перенаправлении, ошибке запроса или превышении лимита в 120 секунд на один запрос скрипт выводит ошибку и завершается с кодом 1.

## Результат

- Среднее время запроса в миллисекундах (`ms`) — сумма длительностей, делённая на 10. Замер каждого запроса начинается перед отправкой и заканчивается после чтения тела ответа.
- Общий объём в байтах (`bytes`) — сумма размеров тел всех ответов без HTTP-заголовков.
- Скорость скачивания в мегабитах в секунду (`Mbps`, Мбит/с). Один Мбит/с равен 1 000 000 бит/с. Формула — `общий объём в байтах × 8 / суммарное время в секундах / 1 000 000`.

Скорость относится к выбранному адресу и включает время ожидания ответа сервера.
